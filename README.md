# ⚡ API Notificações WebSocket

**Servidor WebSocket com salas, histórico de mensagens e notificações em tempo real.**

[![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)]()
[![WebSocket](https://img.shields.io/badge/WebSocket-Real--time-f59e0b?style=for-the-badge)]()

</div>

## ✨ Funcionalidades
- 🏠 Salas independentes (múltiplos utilizadores)
- 📜 Histórico de 50 últimas mensagens por sala
- 👤 Notificações de entrada/saída de utilizadores
- 💓 Ping/Pong para manter a ligação viva

## 🛠️ Setup
```bash
npm install && npm run dev
# Ligar via WebSocket: ws://localhost:3000
# Mensagem inicial: {"type":"join","room":"geral","username":"Vinicius"}
```
